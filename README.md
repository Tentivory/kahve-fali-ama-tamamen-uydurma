# Kahve Falı Ama Tamamen Uydurma

Bu repository, Türkiye'nin (ve dünyanın) en ciddiye alınmayan kahve falı motorudur. 

## Ne Yapar?

`falci.py` çalıştırdığınızda, hayali fincanınızı "okur" ve size tamamen uydurma, absürt yorumlar verir. Hiçbir şey doğru değildir. Amacı eğlenmek, zaman geçirmek ve belki de gerçek falcılara gitmemenizi sağlamaktır.

### Nasıl Çalıştırılır?

```bash
python falci.py
```

Veya Python 3 ile. Bağımlılık yok. Sadece random ve time.

## Özellikler

- %100 uydurma semboller
- Rastgele yorumlar
- Bekleme süresi (ciddiyet için)
- Gizli bir mesaj (decode etmeyi deneyin, belki bir şey çıkar)
- Sonsuza kadar çalışabilir ama önerilmez

## Uyarı

Bu kod gerçek fal değildir. Hayat kararlarınızı buna göre vermeyin. Eğer verirseniz, sorun bende değil.
